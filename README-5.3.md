# Balans 5.3 – Foto först

- Kortare startsideshuvud och mer kompakt fotoingång.
- AI-resultatet visas i ett separat kort med energi, protein, kolhydrater och fett.
- Spara måltid direkt från resultatkortet. Knappen använder det befintliga formuläret och samma lagring (`balans_v1`).
- Justera-väg till originalformuläret, som fortfarande fungerar för manuell registrering och redigering.
- Spara foto med datum flyttat till valfria extra fotoalternativ, inte borttaget.
- AI-fotogodkännande och Cloudflare-inställningar oförändrade.
- Cacheversion uppdaterad för att visa ny design på installerade enheter.

## Uppdatera
Ta säkerhetskopia i den befintliga appen. Packa upp ZIP och ladda upp filerna i GitHub-repots rot. Radera inte appen från hemskärmen: registreringar och foton ligger lokalt på enheten. Testa foto, analys, granskning och spara innan du förlitar dig på den nya versionen.
