# Balans 5.6 – Kompakt layout

Uppdatering av gränssnittet på Idag, Mat, Vikt, Coach och Statistik. Befintliga funktioner och lagringsnyckeln `balans_v1` behålls.

1. Exportera säkerhetskopia från appen innan uppdatering.
2. Ladda upp `index.html` och `service-worker.js` i GitHub-repots rot och ersätt befintliga filer.
3. Kontrollera GitHub Pages-deploy och öppna appen på nytt.
4. Cloudflare Worker behöver **inte** uppdateras för denna designändring.

På Mat: välj AI-foto, Sök mat eller Manuellt. Tidigare måltider är hopfällda. På övriga sidor är detaljer och inställningar hopfällda.
