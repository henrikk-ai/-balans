# Balans 5.2 – Foto först

Designuppdatering som prioriterar foto av måltid.

- Stor foto-knapp direkt på Idag.
- Foto och AI-analys först på Mat-sidan.
- Befintligt formulär för granskning och sparande kvar.
- Mjukare kort, tydligare knappar och uppdaterade färger.
- Oförändrad lokal lagringsnyckel `balans_v1`, AI-server, säkerhetskopiering och övriga funktioner.
- Service worker cache uppdaterad till v5-2.

**Före publicering:** Exportera säkerhetskopia från appen. Packa upp ZIP och ladda upp innehållet i GitHub-projektets rot. Kontrollera på iPhone att foto, AI, sparande och historik fungerar.

Appikoner i 180, 192 och 512 px med mörkgrön bakgrund och cognacfärgad symbol. Logotyp i appens sidhuvud. Service worker-cache uppdaterad. Samma lokala data och AI-konfiguration som tidigare.
